Olive Clarke Real Estate website is a demo project that i created which was inspired by an actual valuator. The website is meant to briefly introduce the services offered and provide a means of contacting the real estate agent/company.
Also, users who have done business with the company can leave reviews which are updated real time to a firebase store.

The technologies behind this project are HTML, CSS, andJavascript.  Firebase database is used for storage.

This website is customizable and incorporates responsive design through css media queries giving users a seamless experience regardless of device used.
